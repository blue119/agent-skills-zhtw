# 其他主機

這些主機安裝了套件，但不在 README 的安裝部分，因為沒有維護者在這些主機上運行當前版本。每一條都是一行：主機及其安裝命令。如需新增一個，請參閱 [新增主機指南](../CONTRIBUTING.md#adding-a-host-guide)。

技能是純粹的 `SKILL.md` 資料夾，因此任何讀取 Agent Skills 配置的代理都可以載入它們。請參閱 [getting-started.md](getting-started.md)。

- **Oh My Pi**: `omp plugin marketplace add addyosmani/agent-skills`，然後 `omp plugin install agent-skills@addy-agent-skills`
